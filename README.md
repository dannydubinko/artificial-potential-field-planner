# Artificial Potential Field Planner

This repository contains Jupyter notebooks implementing an Artificial Potential Field (APF) planner. APF is a method used in robotics for path planning and obstacle avoidance by creating an attractive potential towards the goal and a repulsive potential from obstacles.

## Files
- `main.ipynb`: Main implementation and demonstrations.
- `potential_field.ipynb`: Core potential field algorithms.
- `potential_field_1_itr copy.ipynb`: Iterative testing and copies.
- `resources/`: Contains additional resources used by the notebooks.
